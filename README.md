## Note Pemmbelajaran

content : bagian inti untuk mengisi text,gambar atau element yang ada di kotak tersebut
padding : ruang kosong yang ada dalam dan diantara border dan content, fungsinya agar content tidak terlalu mepet ke garis tepi
border  : garis bingkai yang mengelilingi padding dan content
margin  : ruang kosong yang berada diluar border digunakan untuk mengatur jarak dari element lain
