📝 Note Pembelajaran (CSS Box Model)
Content: Bagian inti untuk mengisi teks, gambar, atau elemen yang ada di dalam kotak tersebut.

Padding: Ruang kosong yang ada di dalam dan di antara border dan content, fungsinya agar konten tidak terlalu mepet ke garis tepi.

Border: Garis bingkai yang mengelilingi padding dan content.

Margin: Ruang kosong yang berada di luar border, digunakan untuk mengatur jarak dari elemen lain.
